# Ночной зоопарк

Игра в браузере. Ночью из клеток разбежались звери! Вокруг темно, видно только светящиеся глаза. Свети фонариком и найди тех, кого просит сторож, пока фонарик не сел.

**Как играть**
- Наверху написано, кого найти, например «сова 0/2, енот 0/1».
- Води пальцем или мышкой, это луч фонарика. Звери прячутся за кустами, камнями, ящиками и на ветках деревьев.
- Увидел нужного зверя — нажми на него. Нажмёшь не на того, и фонарик потеряет 3 секунды.
- Чем больше заряда осталось в конце ночи, тем больше звёзд: от 1 до 3.

**Каждая ночь сложнее**
- Зверей, которых нужно найти, и зверей, которые просто мешают, становится больше, а круг света — меньше.
- С 3-й ночи звери моргают, и глаза видно не всё время.
- С 4-й ночи звери перебегают с места на место.
- С 6-й ночи глаза видно совсем редко.

Сайт состоит из `index.html` (игра) и `art.js` (все рисунки: звери, зоопарк, фонарик). Картинки и звуки сделаны кодом. Пройденные ночи и звёзды сохраняются в браузере.
